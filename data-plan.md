## Collection

    Everyone is present for recording. Many examples per class throughout lifecycle for example for an apple when it is still ripe and throughout the rotting process. Conditions will be indoor and measured in the same environment

    The sensor array will have to be held in the same orientation while measuring objects

    -We will record in similar conditions (similar distance however different orientations around the object if possible)
    -use 20% of these measurements for testing

## Risk

    Classes with common compounds could trigger the wrong sensors adding noise to measurements
