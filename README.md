# SNIFF32 👃
*"If it smells, we can define it."*

**SNIFF32** is a TinyML embedded project developed for the Embedded Programming 2 course. It utilizes an ESP32-S3 microcontroller and a 5-sensor gas array to detect, classify, and identify various odors including fresh food, decomposing matter, and ambient air. 

## Hardware
* **Microcontroller:** ESP32-S3
* **Sensors:** VOC, NH3, H2S, ETOH, ODOR

## Project Scope
The goal of this project is to sample real-world gas emissions from various items throughout their lifecycle (e.g., a rotting apple) and train an Edge Impulse model to run locally on the ESP32-S3 for real-time scent classification.
